# 第一阶段交付记录

日期：2026-10-30（Asia/Singapore）

已建立可在本地检索、追溯文件及原帖来源的首批机构样本库，供后续队内 HTTP 服务使用。

## 数据与验证

- 10 个有 CAD 的来源，17 个入库附件；1754 个文件，其中 CAD 1736 个。文件数包含不同附件中的重复零件，不等于独立机构数。
- 26 张机构卡片，对应20个不同CAD入口文件，其中6张是同一悬挂STEP中的子定义，未导出为独立装配。
- 分类：底盘5、悬挂6、机械臂3、抬升2、云台3、轮腿1、舵轮1、减速箱2、抓取1、轮组2。
- 全部1754个文件SHA-256核验通过；26张卡片验证通过。
- 9类关键词查询第一条结果类别符合预期；这是词法基线的冒烟验收，不是自然语言检索质量评测。
- 35项现有脚本测试通过。
- 17张卡片关联原生依赖报告，9张关联STEP静态几何报告。
- 125个原生装配已读取保存的直接引用；引用结果包括1152条潜在本地匹配、772条歧义匹配、114条包外引用。均未据此认定依赖已解析成功。

## 使用

在本目录运行：

```powershell
.venv\Scripts\python.exe tools\library.py search "舵轮"
.venv\Scripts\python.exe tools\library.py search "轮腿"
.venv\Scripts\python.exe tools\library.py validate
```

查询返回机构名称、原帖链接、CAD入口路径、文件指纹、验证状态和限制。完整卡片位于 catalog/modules.jsonl；本地索引为 catalog/library.sqlite3。

## 证据边界与待办

功能分类多数依据文件名及附带说明，机构边界仍需工程复核。来源中的本地说明快照与论坛原文快照已区分；未可靠识别的队名保留为待核对。用户提供文件的本地SHA-256只证明本次入库一致性，不证明与论坛声明校验和一致。

原生配合、配置、运动范围、安装接口、材料及质量未完成验证；保存引用读取不等于完整装配可加载。子定义保留源文件定位。

本批是从下载目录选取的首批机构样本，不代表全部下载资料已入库。HTTP服务、向量检索、语义重排和插件自动装配属于后续阶段。本阶段未发布任何文件；第三方CAD授权需分别确认。

详细结果见 phase1-acceptance.json、catalog-validation.json、native-dependencies.jsonl、step-inspection.jsonl；机构浏览见 SAMPLE_CATALOG.md。
